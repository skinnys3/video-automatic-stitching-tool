📦 目录结构
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  video-automatic v1.4.0/
  ├── video-join-v12.py         ← 主程序（勿删）
  ├── win-拼接+水印v1.4.bat     ← Windows 启动脚本
  ├── win-配置GPU加速v1.4.bat   ← GPU 配置工具
  ├── config.json               ← 配置文件（首次运行自动生成）
  ├── 使用说明.txt               ← 本文件
  ├── come/                     ← 放入待处理的 MP4 视频
  └── for/                      ← 输出目录（自动创建）

🚀 快速开始（Windows）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 将 MP4 视频文件放入 come/ 文件夹
     要求命名格式: 书名-第XX集.mp4
     例如: 龙王归来-第001集.mp4

  2. 双击运行 win-拼接+水印v1.4.bat

  3. 输出文件在 for/ 文件夹中
     横版源 → 同时输出横版(1280×720) + 竖版(720×1280)
     竖版源 → 只输出竖版(720×1280)

🎮 GPU 加速（v1.4.0 新功能）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  首次运行时自动检测 NVIDIA CUDA 是否可用，
  并生成 config.json 配置文件。

  如需手动开关 GPU 加速:
  ① 双击 win-配置GPU加速v1.4.bat
  ② 选择 1 开启 / 2 关闭

  GPU 加速生效条件:
  • Windows 系统
  • NVIDIA 显卡 + 最新驱动
  • CUDA 版 ffmpeg（支持 scale_cuda / overlay_cuda）
  • h264_nvenc 编码器

  不满足条件时会自动降级为 CPU 编码，不影响使用。

🐞 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: 提示"python 不是内部或外部命令"
  A: 请安装 Python: https://www.python.org/downloads/

  Q: 提示"未找到 ffmpeg"
  A: 下载 ffmpeg 并将 ffmpeg.exe 所在目录加入系统 PATH

  Q: 输出视频预览为黑色
  A: macOS 专有问题，v1.3+ 已自动嵌入首帧封面

  Q: GPU 加速没生效
  A: 运行 win-配置GPU加速v1.4.bat → 选择 3 检测兼容性
